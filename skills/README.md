# Personal skills

Add personal skills here as `<name>/SKILL.md`. Include `name` and `description` frontmatter. Put references and executable helpers inside the skill directory.

Bundled skill collections live in `../plugins/<plugin>/skills/`. Edit their authoritative files there. Drafts live in `../development_skills/`.

This directory currently contains no installed personal skills. Link it into your harness's skill directory when you add one.
